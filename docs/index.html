The problem

Phishing works because defenses lag

01

Blocklists are reactive

Safe Browsing only catches reported domains — hours after they're live.

02

Typosquatting costs $1

Registering g00gle.xyz takes seconds. Most users won't notice.

03

Network tools are blind to the browser

A page that loads clean HTML and renders a phishing form via JavaScript is invisible to proxies.

The white space

Nobody scores domains at navigation time

No tool combines AI + community signals at the browser layer, in real time, at the moment you click.

Network layer — firewalls, DNS, proxies
Sees HTTP payloads. Blind to client-side JavaScript rendering.
Existing
Device layer — endpoint agents
Sees OS state. Can't see inside a browser tab.

Browser layer — Domain Authenticator

Features

What it does

Each feature closes a specific gap.

Trust score badge on every tab

Color-coded score updates automatically on every navigation. Green = trusted, red = dangerous.

Analyse before clicking the link

Right-click and check if the link is safe even before visiting it.

Warning banner on suspicious sites

Amber banner injected at the top of the page for caution-level domains. Dismissible, auto-disappears after 10s.

Full analysis in the popup

Click the shield icon for the complete breakdown — trust gauge, per-signal scores, plain-English AI explanation.

Community voting

Vote Safe / Suspicious / Unsafe from the popup for the sites not in the verified list. Weighted votes from real users feed back into scoring.

Report AI mistakes

Flag wrong verdicts directly from the popup. Creates a feedback loop that improves accuracy over time.

Brand similarity
30%Typosquatting, digit substitution (g00gle)
AI verdict
22%Semantic patterns heuristics miss
TLD risk
18%.xyz, .top, .buzz and 30+ high-abuse TLDs
Entropy
10%DGA-generated random-looking domains
Subdomain abuse
10%paypal.com.evil.xyz patterns
Characters + length
10%Hyphen/digit abuse, unusual length
Combo override: digit substitution of a known brand on a high-risk TLD forces a dangerous verdict immediately.
Community voting

AI starts it. Humans refine it.

Community votes correct AI mistakes on websites — only on new domains with no threat-feed history in the extension.

STEP 1

Visit a domain

AI + heuristics produce initial verdict

STEP 2

Cast a vote

Safe, Suspicious, or Unsafe

STEP 3

Vote is weighted

Active reviewers carry up to 2×

STEP 4

Consensus shifts score

60%+ majority escalates or de-escalates

⚖️
Weighted votes — New users: 1×. 10+ reviews: 1.5×. 50+: 2× (capped).
🔢
Minimum threshold — Needs 2+ votes before community signal activates.
🔼
Unsafe majority — 60%+ unsafe votes shifts scoring toward higher risk.
🔽
Safe majority — 60%+ safe votes with 50%+ confidence shifts scoring toward lower risk.
🔄
Cache busts on vote — Next visitor gets fresh analysis reflecting new community data.
